Binary Algebraic Structures

Definition of binary algebraic structures

A binary algebraic structure \(\langle S, *\rangle\) is a set together with a binary operation \(*\) on \(S\).

Definition of left identity element and right identity element

\(\forall\) binary algebraic structure \(\langle S, *\rangle\),
  • \(e \in S\) is called a left identity element of \(S\) iff \(\forall\ a \in S\), \(e * a = a\).
  • \(e \in S\) is called a right identity element of \(S\) iff \(\forall\ a \in S\), \(a * e = a\).
  • \(e \in S\) is called a two-sided identity element of \(S\) iff \(\forall\ a \in S\), \(e * a = a * e = a\).

Uniqueness of two-sided identity element

\(\forall\) binary algebraic structure \(\langle S, *\rangle\) has at most one two-sided identity element.
Proof.
Suppose \(\exists\ \langle S, *\rangle\) has at least two-sided identity elements \(e_{1}\) and \(e_{2}\), and \(e_{1} \ne e_{2}\). Then
  • Because \(e_{1}\) is a two-sided identity element, there is \[ e_{1} * e_{2} = e_{2} * e_{1} = e_{2}. \]
  • Because \(e_{2}\) is a two-sided identity element, there is \[ e_{2} * e_{1} = e_{1} * e_{2} = e_{1}. \]
Therefore, \(e_{1} = e_{2}\), which is a contradiction. Hence, \(\forall\) binary algebraic structure \(\langle S, *\rangle\) has at most one two-sided identity element.

\(\blacksquare\)

Identity element of isomorphism

Suppose \(\langle S, *\rangle\) has an identity element \(e\) for \(*\). If \(f : S \rightarrow S^{\prime}\) is an isomorphism of \(\langle S, *\rangle\) with \(\langle S^{\prime}, *^{\prime}\rangle\), then \(f(e)\) is an identity element for the binary operation \(*^{\prime}\) on \(S^{\prime}\).
Proof.
Because \(f : S \rightarrow S^{\prime}\) is an isomorphism of \(\langle S, *\rangle\) with \(\langle S^{\prime}, *^{\prime}\rangle\), \(\forall\ s^{\prime} \in S^{\prime}\), \(\exists\ s \in S\) such that \(f(s) = s^{\prime}\). Then there are \[ f(e) *^{\prime} s^{\prime} = f(e) *^{\prime} f(s) = f(e * s), \] and \[ s^{\prime} *^{\prime} f(e) = f(s) *^{\prime} f(e) = f(s * e). \] Because \(e\) is the identity element of \(\langle S, *\rangle\), there is \(e * s = s * e = s\). Therefore, \[ f(e) *^{\prime} s^{\prime} = f(e * s) = f(s) = s^{\prime}, \] and \[ s^{\prime} *^{\prime} f(e) = f(s * e) = f(s) = s^{\prime}, \] which means that \(f(e) *^{\prime} s^{\prime} = s^{\prime} *^{\prime} f(e) = s^{\prime}\). Hence, \(f(e)\) is an identity element for the binary operation \(*^{\prime}\) on \(S^{\prime}\).

\(\blacksquare\)

Definition of left inverse and right inverse

\(\forall\) binary algebraic structure \(\langle S, *\rangle\) such that \(\exists\ e \in S \) is the identity element of \(\langle S, *\rangle\).
