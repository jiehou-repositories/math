Functions

Definition of functions

\(\forall\) sets \(A\) and \(B\), a function \(f\) from \(A\) to \(B\) is a relation between \(A\) and \(B\) such that \(\forall\ a \in A\) and \(\forall\ b_{1}, b_{2} \in B\), if \(a f b_{1}\) and \(a f b_{2}\), then \(b_{1} = b_{2}\). \(f\) is also called a map or mapping from \(A\) to \(B\), denoted as \(f : A \rightarrow B\). \(\forall\ a \in A\) and \(\forall\ b \in B\), if \(a f b\), then it is written as \(f(a) = b\).
  • Domain: \(A\) is called the domain of \(f\).
  • Codomain: \(B\) is called the codomain of \(f\).
  • Range: \(f[A] = \{f(a)\ |\ a \in A\}\).
Common types of functions:
  • Injective function: \(\forall\) sets \(A\) and \(B\), \(f : A \rightarrow B\) is called an injective function iff \(\forall\ a_{1}, a_{2} \in A\), if \(a_{1} \ne a_{2}\), then \(f(a_{1}) \ne f(a_{2})\).
  • Surjective function: \(\forall\) sets \(A\) and \(B\), \(f : A \rightarrow B\) is called an surjective function iff \(\forall\ b \in B\), \(\exists\ a \in A\), \(f(a) = b\), which is also \(f[A] = B\).
  • Bijective function: \(\forall\) sets \(A\) and \(B\), \(f : A \rightarrow B\) is called an bijective function iff \(f\) is both injective and surjective.
  • Identity function: \(\forall\) set \(A\), \(f : A \rightarrow A\) is called the identity function on \(A\) iff \(\forall\ a \in A\), \(f(a) = a\).

Definition of composite functions

\(\forall\) sets \(A\), \(B\) and \(C\), \(\forall\) function \(f : A \rightarrow B\) and \(\forall\) \(g : B \rightarrow C\), a function \(h : A \rightarrow C\) is the composite function \(g\) of \(f\) iff \(\forall\ a \in A\), \(h(a) = g(f(a))\). \(h\) is denoted as \(g \circ f\).
  • Left inverse: \(\forall\) sets \(A\) and \(B\), \(f : A \rightarrow B\) has a left inverse iff \(\exists\ g : B \rightarrow A\), \(g \circ f\) is the identity function on \(A\).
  • Right inverse: \(\forall\) sets \(A\) and \(B\), \(f : A \rightarrow B\) has a right inverse iff \(\exists\ g : B \rightarrow A\), \(f \circ g\) is the identity function on \(B\).

Conditions of injection, surjection and bijection

\(\forall\) sets \(A\) and \(B\), \(\forall\) function \(f : A \rightarrow B\),
  • \(f\) is injective iff \(f\) has a left inverse.
  • \(f\) is surjective iff \(f\) has a right inverse.
  • \(f\) is injective iff \(f\) has both a left inverse and a right inverse.
  • If \(A\) and \(B\) are finite sets and \(|A| = |B|\), then \(f\) is injective iff \(f\) is surjective.
Proof.
    • The following proves that \(f\) is injective \(\Rightarrow\) \(f\) has a left inverse.
      Define a function \(g : B \rightarrow A\) as the following way: Because \(A \ne \varnothing\), \(\exists\ x \in A\). \(\forall\ b \in B\), if \(\exists\ a \in A\) such that \(f(a) = b\), then \(g(b) = a\); otherwise, if \(\nexists\ a \in A\) such that \(f(a) = b\), then \(g(b) = x\).
      • The following proves that \(g\) is well-defined.
        Because \(f\) is injective, if \(\exists\ a \in A\) such that \(f(a) = b\), then \(\forall\ c \in A\), if \(c \ne a\), then \(f(c) \ne b\). Therefore, \(g(b)\) is uniquely determined.
      • The following proves that \(f\) has a left inverse.
        \(\forall\ a \in A\), \(\exists\ b \in B\), \(f(a) = b\). Then \(g(b) = a\), and \((g \circ f)(a) = g(f(a)) = g(b) = a\). Therefore, \(g \circ f\) is the identity function on \(A\), which means that \(f\) has a left inverse.
    • The following proves that \(f\) has a left inverse \(\Rightarrow\) \(f\) is injective.
      Because \(f\) has a left inverse, \(\exists\ g : B \rightarrow A\), \(g \circ f\) is the identity function on \(A\). \(\forall\ a \in A\), \((g \circ f)(a) = g(f(a)) = a\). Suppose that \(f\) is not injective. \(\exists\ a_{1}, a_{2} \in A\), \(a_{1} \ne a_{2}\) and \(f(a_{1}) = f(a_{2})\). Then, \((g \circ f)(a_{1}) = g(f(a_{1})) = a_{1}\), \((g \circ f)(a_{2}) = g(f(a_{2})) = a_{2}\). \(\exists\ b \in B\), \(f(a_{1}) = f(a_{2}) = b\). Therefore, \(g(b) = a_{1}\) and \(g(b) = a_{2}\), which contradicts \(a_{1} \ne a_{2}\). Therefore, \(f\) is injective.
    To sum up, \(f\) is injective iff \(f\) has a left inverse.
    • The following proves that \(f\) is surjective \(\Rightarrow\) \(f\) has a right inverse.
      Define a function \(g : B \rightarrow A\) as the following way: \(\forall\ b \in B\), \(\exists\ a \in A\) such that \(f(a) = b\), \(g(b) = a\).
      • The following proves that \(g\) is well-defined.
        Because \(f\) is surjective, \(\forall\ b \in B\), \(\exists\ a \in A\) such that \(f(a) = b\).
      • The following proves that \(f\) has a right inverse.
        \(\forall\ b \in B\), \(\exists\ a \in A\), \(f(a) = b\). Then \(g(b) = a\), and \((f \circ g)(b) = f(g(b)) = f(a) = b\). Therefore, \(f \circ g\) is the identity function on \(B\), which means that \(f\) has a right inverse.
    • The following proves that \(f\) has a right inverse \(\Rightarrow\) \(f\) is surjective.
      Because \(f\) has a right inverse, \(\exists\ g : B \rightarrow A\), \(f \circ g\) is the identity function on \(B\). \(\forall\ b \in B\), \((f \circ g)(b) = f(g(b)) = b\). Suppose that \(f\) is not surjective. \(\exists\ b_{0} \in B\), \(\nexists\ a \in A\) such that \(f(a) = b_{0}\). Then, \((f \circ g)(b_{0}) = f(g(b_{0})) = b_{0}\). \(\exists\ a_{0} \in A\), \(g(b_{0}) = a_{0}\). Then, \(f(g(b_{0})) = f(a_{0}) = b_{0}\), which is a contradiction. Therefore, \(f\) is surjective.
    • The following proves that \(f\) is bijective \(\Rightarrow\) \(f\) has both a left inverse and a right inverse.
      Because \(f\) is bijective, \(f\) is both injective and surjective. Because \(f\) is injective, \(f\) has a left inverse. Because \(f\) is surjective, \(f\) has a right inverse.
    • The following proves that \(f\) has both a left inverse and a right inverse \(\Rightarrow\) \(f\) is bijective.
      Because \(f\) has a left inverse, \(f\) is injective. Because \(f\) has a right inverse, \(f\) is surjective. Because \(f\) is both injective and surjective, \(f\) is bijective.
  • Because \(|A| = |B|\), let \(|A| = |B| = n\) and \(A = \{a_{1}, \cdots, a_{n}\}\), \(B = \{b_{1}, \cdots, b_{n}\}\), where \(n \in \mathbb{Z}^{+}\).
    • The following proves that \(f\) is injective \(\Rightarrow\) \(f\) is surjective.
      Because \(f\) is injective, \(\forall\ x, y \in A\), if \(x \ne y\), then \(f(x) \ne f(y)\). Because \(|A| = n\), \(|f[A]| = n\). Therefore, \(|f[A]| = |B| = n\), \(f\) is surjective.
    • The following proves that \(f\) is surjective \(\Rightarrow\) \(f\) is injective.
      Suppose that \(f\) is not injective. \(\exists\ x, y \in A\), \(x \ne y\) and \(f(x) = f(y)\). Because \(|A| = n\), \(|f[A]| < n\). However, \(f\) is surjective, \(|f[A]| = |B| = n\), which is a contradiction. Therefore, \(f\) is injective.

\(\blacksquare\)

Definition of binary operations

A binary operation \(*\) on a set \(S\) is a function \(* : S \times S \rightarrow S\). \(\forall\ a, b \in S\), \(*(a, b)\) is denoted as \(a * b\).
  • Commutative binary operation
    For a binary operation \(* : S \times S \rightarrow S\), \(*\) is commutative iff \(\forall\ a, b \in S\), \(a * b = b * a\).
  • Associative binary operation
    For a binary operation \(* : S \times S \rightarrow S\), \(*\) is associative iff \(\forall\ a, b, c \in S\), \((a * b) * c = a * (b * c)\).
Notations:
  • \(\forall\ a \in S\), \(a = a^{1*} = a^{*1}\).
  • \(\forall\ n \in \mathbb{Z}^{+}\) and \(\forall\ a \in S\), \(a^{(n + 1)*} = a * a^{n*}\) and \(a^{*(n + 1)} = a^{*n} * a\).
