Linear Maps

Definition of linear maps

A linear map from \(V\) to \(W\) is a function \(T: V \rightarrow W\) with the following properties
  • Additivity
    \(\forall\ \textbf{u}, \textbf{v} \in V\), \(T(\textbf{u} + \textbf{v}) = T\textbf{u} + T\textbf{v}\).
  • Homogeneity
    \(\forall\ \lambda \in F\) and \(\forall\ \textbf{v} \in V\), \(T(\lambda\textbf{v}) = \lambda(T\textbf{v})\).
The set of all linear maps from \(V\) to \(W\) is denoted \(\mathcal{L}(V, W)\).

Existence and uniqueness of linear maps

Suppose \(\{\textbf{v}_{1}, \dots, \textbf{v}_{n}\}\) is a basis of \(V\) and \(\forall\ \textbf{w}_{1}, \dots, \textbf{w}_{n} \in W\). Then there exists a unqiue linear map \(T: V \rightarrow W\) such that \(T\textbf{v}_{i} = \textbf{w}_{i}\) for \(1 \leq i \leq n\) and \(i \in \mathbb{Z}^{+}\).
