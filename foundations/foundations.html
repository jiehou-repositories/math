Foundations

Definition of relations

\(\forall\) sets \(X\) and \(Y\), a relation \(R\) between \(X\) and \(Y\) is a subset of \(X \times Y\).
\(\forall\ x \in X\) and \(\forall\ y \in Y\), \((x, y) \in R\) is denoted as \(x R y\).

Definition of equality relation

The equality relation \(=\) on a set \(S\) is defined by \(\{(x, x)\ |\ x \in S\}\).

Definition of equivalence relation

An equivalence relation \(\sim\) on a set \(S\) is one satisfying following properties:
  • Reflexive:
    \(\forall\ x \in S\), \(x \sim x\).
  • Symmetric:
    \(\forall\ x, y \in S\), if \(x \sim y\), then \(y \sim x\).
  • Transitive:
    \(\forall\ x, y, z \in S\), if \(x \sim y\) and \(y \sim z\), then \(x \sim z\).

Definition of functions

\(\forall\) sets \(X\) and \(Y\), a function \(f\) mapping \(X\) into \(Y\) is a relation between \(X\) and \(Y\) such that \(\forall\ x \in X\) and \(\forall\ y_{1}, y_{2} \in Y\), if \(x f y_{1}\) and \(x f y_{2}\), then \(y_{1} = y_{2}\).
\(f\) is also called a map or mapping of \(X\) into \(Y\), denoted as \(f : X \rightarrow Y\). \(\forall\ x \in X\) and \(\forall\ y \in Y\), if \(x f y\), then it is written as \(f(x) = y\).
  • Domain: \(X\) is called the domain of \(f\).
  • Codomain: \(Y\) is called the domain of \(f\).
  • Range: \(f[X] = \{f(x)\ |\ x \in X\}\).

Definition of binary operations

A binary operation \(*\) on a set \(S\) is a function \(* : S \times S \rightarrow S\). \(\forall\ a, b \in S\), \(*(a, b)\) is denoted as \(a * b\).
A binary algebraic structure \(\langle S, *\rangle\) to be a set together with a binary operation \(*\) on \(S\).

Definition of induced operations

For a binary operation \(* : S \times S \rightarrow S\), \(\forall\ H \subseteq S\), \(H\) is closed under \(*\) iff \(\forall\ a, b \in H\), \(a * b \in H\). The binary operation on \(H\) given by restrictig \(*\) to \(H\) is the induced operation of \(*\) on \(H\).

Definition of commutative and associative operations

For a binary operation \(* : S \times S \rightarrow S\), \(*\) is commutative iff \(\forall\ a, b \in S\), \(a * b = b * a\).
For a binary operation \(* : S \times S \rightarrow S\), \(*\) is associative iff \(\forall\ a, b, c \in S\), \((a * b) * c = a * (b * c)\).

Definition of isomorphic binary structures

Let \(\langle S, *\rangle\) and \(\langle S^{\prime}, *^{\prime}\rangle\) be binary algebraic structures. An isomorphism of \(S\) with \(S^{\prime}\) is a one-to-one function \(f\) mapping \(S\) onto \(S^{\prime}\) such that \(\forall\ x, y \in S\), \(f(x * y) = f(x) * f(y)\). If such a map \(f\) exists, then \(S\) and \(S^{\prime}\) are isomorphic binary structures, which we denote by \(S \simeq S^{\prime}\), ommitting the \(*\) and \(*^{\prime}\) from the notation.

Definition of identity element

Let \(\langle S, *\rangle\) be a binary structure. An element \(e\) of \(S\) is an identity element for \(*\) if \(\forall\ s \in S\), \(e * s = s * e = s\).

Uniqueness of identity element

A binary structure \(\langle S, *\rangle\) has at most one identity element.
Proof.
Suppose \(\langle S, *\rangle\) has identity elements \(e_{1}\) and \(e_{2}\), and \(e_{1} \ne e_{2}\). Then
  • Because \(e_{1}\) is an identity element, there is \[ e_{1} * e_{2} = e_{2} * e_{1} = e_{1}. \]
  • Because \(e_{2}\) is an identity element, there is \[ e_{2} * e_{1} = e_{1} * e_{2} = e_{2}. \]
Therefore, \( e_{1} * e_{2} = e_{2} * e_{1} = e_{1} = e_{2}\), which is a contradiction. Hence, \(\langle S, *\rangle\) has at most one identity element.

\(\blacksquare\)

Identity element of isomorphism

Suppose \(\langle S, *\rangle\) has an identity element \(e\) for \(*\). If \(f : S \rightarrow S^{\prime}\) is an isomorphism of \(\langle S, *\rangle\) with \(\langle S^{\prime}, *^{\prime}\rangle\), then \(f(e)\) is an identity element for the binary operation \(*^{\prime}\) on \(S^{\prime}\).
Proof.
Because \(f : S \rightarrow S^{\prime}\) is an isomorphism of \(\langle S, *\rangle\) with \(\langle S^{\prime}, *^{\prime}\rangle\), \(\forall\ s^{\prime} \in S^{\prime}\), \(\exists\ s \in S\) such that \(f(s) = s^{\prime}\). Then there are \[ f(e) *^{\prime} s^{\prime} = f(e) *^{\prime} f(s) = f(e * s), \] and \[ s^{\prime} *^{\prime} f(e) = f(s) *^{\prime} f(e) = f(s * e). \] Because \(e\) is the identity element of \(\langle S, *\rangle\), there is \(e * s = s * e = s\). Therefore, \[ f(e) *^{\prime} s^{\prime} = f(e * s) = f(s) = s^{\prime}, \] and \[ s^{\prime} *^{\prime} f(e) = f(s * e) = f(s) = s^{\prime}, \] which means that \(f(e) *^{\prime} s^{\prime} = s^{\prime} *^{\prime} f(e) = s^{\prime}\). Hence, \(f(e)\) is an identity element for the binary operation \(*^{\prime}\) on \(S^{\prime}\).

\(\blacksquare\)
