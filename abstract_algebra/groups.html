Groups

Definition of groups

A binary algebraic structure \(\langle G, *\rangle\) is a group iff
  • Associativity of \(*\)
    \(\forall\ a, b, c \in G\), \((a * b) * c = a * (b * c)\).
  • Identity element of \(*\)
    \(\exists\ e \in G\), \(\forall\ a \in G\), \(e * a = a * e = a\).
  • Inverse in \(*\)
    \(\forall\ a \in G\), \(\exists\ a^{\prime} \in G\) such that \(a * a^{\prime} = a^{\prime} * a = e\).

Definition of abelian groups

A group \(\langle G, *\rangle\) is abelian if its binary operation is commutative.

Left and right cancellation laws

\(\forall\) group \(\langle G, *\rangle\) holds the left and right cancellation laws.
  • \(\forall\ a, b, c \in G\), if \(a * b = a * c\), then \(b = c\).
  • \(\forall\ a, b, c \in G\), if \(b * a = c * a\), then \(b = c\).
Proof. Because \(\langle G, *\rangle\) is a group, \(\exists\ e \in G\) is the identity element. \(\forall\ a \in G\), \(\exists\ a^{\prime} \in G\) such that \(a * a^{\prime} = a^{\prime} * a = e\).
  • \(\forall\ a, b, c \in G\), if \(a * b = a * c\), then there is \[ a^{\prime} * (a * b) = a^{\prime} * (a * c) \quad \Rightarrow \quad (a^{\prime} * a) * b = (a^{\prime} * a) * c \quad \Rightarrow \quad e * b = e * c \quad \Rightarrow \quad b = c. \]
  • \(\forall\ a, b, c \in G\), if \(b * a = c * a\), then \(b = c\). \[ (b * a) * a^{\prime} = (c * a) * a^{\prime} \quad \Rightarrow \quad b * (a * a^{\prime}) = c * (a * a^{\prime}) \quad \Rightarrow \quad b * e = c * e \quad \Rightarrow \quad b = c. \]

\(\blacksquare\)

Unique solution

\(\forall\) group \(\langle G, *\rangle\), \(\forall\ a, b \in G\), \(\exists !\ x, y \in G\) such that \(a * x = b\) and \(y * a = b\).
Proof. Because \(\langle G, *\rangle\) is a group, \(\exists\ e \in G\) is the identity element.
  • Existence
    \(\forall\ a \in G\), \(\exists\ a^{\prime} \in G\) is an inverse of \(a\). There are
    • \(a * (a^{\prime} * b) = (a * a^{\prime}) * b = e * b = b\).
    • \((b * a^{\prime}) * a = b * (a^{\prime} * a) = b * e = b\).
    Therefore, \(\exists\ x = a^{\prime} * b \in G\) such that \(a * x = b\). \(\exists\ y = b * a^{\prime} \in G\) such that \(y * a = b\).
  • Uniqueness
    • Suppose \(\exists\ x_{1}, x_{2} \in G\) such that \(a * x_{1} = b\) and \(a * x_{2} = b\) and \(x_{1} \ne x_{2}\). Therefore, \(a * x_{1} = a * x_{2}\). According to the left cancellation law, \(x_{1} = x_{2}\), which is a contradiction. Hence, \(\exists !\ x \in G\) such that \(a * x = b\).
    • Suppose \(\exists\ y_{1}, y_{2} \in G\) such that \(y_{1} * a = b\) and \(y_{2} * a = b\) and \(y_{1} \ne y_{2}\). Therefore, \(y_{1} * a = y_{2} * a\). According to the right cancellation law, \(y_{1} = y_{2}\), which is a contradiction. Hence, \(\exists !\ y \in G\) such that \(y * a = b\).

\(\blacksquare\)

Unique inverse

\(\forall\) group \(\langle G, *\rangle\), \(\forall\ a \in G\), \(\exists !\ a^{\prime} \in G\) is the inverse of \(a\).
Proof. \(\forall\ a \in G\), suppose that \(\exists\ a_{1}^{\prime}, a_{2}^{\prime} \in G\) are both inverses of \(a\) and \(a_{1}^{\prime} \ne a_{2}^{\prime}\). Let \(e \in G\) be the identity element of \(\langle G, *\rangle\). Because \(a_{1}^{\prime} * a = e\) and \(a_{2}^{\prime} * a = e\), there is \(a_{1}^{\prime} * a = a_{2}^{\prime} * a\). Therefore, \(a_{1}^{\prime} = a_{2}^{\prime}\), which is a contradiction. Hence, \(\forall\ a \in G\), \(\exists !\ a^{\prime} \in G\) is the inverse of \(a\).

\(\blacksquare\)

Inverse of the operation

\(\forall\) group \(\langle G, *\rangle\), \(\forall\ a, b \in G\), \((a * b)^{\prime} = b^{\prime} * a^{\prime}\).
Proof. \(\forall\) group \(\langle G, *\rangle\), suppose \(e \in G\) is the identity element of \(\langle G, *\rangle\). There are \[ (a * b) * (b^{\prime} * a^{\prime}) = ((a * b) * b^{\prime}) * a^{\prime} = (a * (b * b^{\prime})) * a^{\prime} = (a * e) * a^{\prime} = a * a^{\prime} = e, \] and \[ (b^{\prime} * a^{\prime}) * (a * b) = ((b^{\prime} * a^{\prime}) * a) * b = (b^{\prime} * (a^{\prime} * a)) * b = (b^{\prime} * e) * a = b^{\prime} * b = e. \] Hence, \((a * b)^{\prime} = b^{\prime} * a^{\prime}\).

\(\blacksquare\)
