Foundations

Definition of relations

\(\forall\) sets \(X\) and \(Y\), a relation \(R\) between \(X\) and \(Y\) is a subset of \(X \times Y\). \(\forall\ x \in X\) and \(\forall\ y \in Y\), \((x, y) \in R\) is denoted as \(x R y\).
  • Equality relation
    The equality relation \(=\) on a set \(S\) is defined by \(\{(x, x)\ |\ x \in S\}\).
  • Equivalence relation
    An equivalence relation \(\sim\) on a set \(S\) is one satisfying following properties:
    • Reflexive:
      \(\forall\ x \in S\), \(x \sim x\).
    • Symmetric:
      \(\forall\ x, y \in S\), if \(x \sim y\), then \(y \sim x\).
    • Transitive:
      \(\forall\ x, y, z \in S\), if \(x \sim y\) and \(y \sim z\), then \(x \sim z\).

Definition of functions

\(\forall\) sets \(X\) and \(Y\), a function \(f\) mapping \(X\) into \(Y\) is a relation between \(X\) and \(Y\) such that \(\forall\ x \in X\) and \(\forall\ y_{1}, y_{2} \in Y\), if \(x f y_{1}\) and \(x f y_{2}\), then \(y_{1} = y_{2}\). \(f\) is also called a map or mapping of \(X\) into \(Y\), denoted as \(f : X \rightarrow Y\). \(\forall\ x \in X\) and \(\forall\ y \in Y\), if \(x f y\), then it is written as \(f(x) = y\).
  • Domain: \(X\) is called the domain of \(f\).
  • Codomain: \(Y\) is called the codomain of \(f\).
  • Range: \(f[X] = \{f(x)\ |\ x \in X\}\).

Definition of binary operations

A binary operation \(*\) on a set \(S\) is a function \(* : S \times S \rightarrow S\). \(\forall\ a, b \in S\), \(*(a, b)\) is denoted as \(a * b\).
  • Commutative binary operation
    For a binary operation \(* : S \times S \rightarrow S\), \(*\) is commutative iff \(\forall\ a, b \in S\), \(a * b = b * a\).
  • Associative binary operation
    For a binary operation \(* : S \times S \rightarrow S\), \(*\) is associative iff \(\forall\ a, b, c \in S\), \((a * b) * c = a * (b * c)\).
Notations:
  • \(\forall\ a \in S\), \(a = a^{1*} = a^{*1}\).
  • \(\forall\ n \in \mathbb{Z}^{+}\) and \(\forall\ a \in S\), \(a^{(n + 1)*} = a * a^{n*}\) and \(a^{*(n + 1)} = a^{*n} * a\).

Definition of induced operations

For a binary operation \(* : S \times S \rightarrow S\), \(\forall\ H \subseteq S\), \(H\) is closed under \(*\) iff \(\forall\ a, b \in H\), \(a * b \in H\). The binary operation on \(H\) given by restrictig \(*\) to \(H\) is the induced operation of \(*\) on \(H\).

Definition of isomorphic binary structures

Let \(\langle S, *\rangle\) and \(\langle S^{\prime}, *^{\prime}\rangle\) be binary algebraic structures. An isomorphism of \(S\) with \(S^{\prime}\) is a one-to-one function \(f\) mapping \(S\) onto \(S^{\prime}\) such that \(\forall\ x, y \in S\), \(f(x * y) = f(x) * f(y)\). If such a map \(f\) exists, then \(S\) and \(S^{\prime}\) are isomorphic binary structures, which we denote by \(S \simeq S^{\prime}\), ommitting the \(*\) and \(*^{\prime}\) from the notation.
